## Starting a New Sub-Project

1. Create `docs/<sub-project>/DESIGN.md` (Phase -1).
2. Create `docs/<sub-project>/PROGRESS.md` with curriculum checkboxes; use `PLAN.md` as the reference.
3. Add a new row to the table above.
4. Scaffold a NestJS app under `nestjs/<sub-project>/` (Phase 0).
5. Proceed through Phases 0-8 in order.

See the top of `PLAN.md` for the next domain ideas.
